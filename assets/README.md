# UEMCP 品牌素材

UEMCP 的标志是一段 **U 形桥接路径**：两个端口节点由一条曲线相连，路径最低处的**菱形是网关节点**。一条线把两端接起来——这就是 UEMCP 在任意 MCP 客户端与编辑器之间做「桥」的含义。全部图形为自有矢量形状，不含任何第三方商标元素。

## 文件

| 文件 | 规格 | 用途 |
| --- | --- | --- |
| `logo.svg` | 512×512 viewBox，矢量，透明背景 | **主标志**（图形 + 字标），用于浅色背景 |
| `logo-on-dark.svg` | 512×512 viewBox，矢量，透明背景 | 主标志的深色背景适配版（`#F7F9FC` + `#22D3EE`） |
| `logo-mark.svg` | 512×512 viewBox，矢量，深色圆角底 | **仅图标**（无文字），favicon / 应用图标，32×32 可辨 |
| `logo-512.png` | 512×512，PNG（RGBA） | 主标志位图，用于文档、商店页、幻灯片 |
| `logo-128.png` | 128×128，PNG（RGBA） | 主标志小尺寸位图 |
| `social-preview.png` | 1280×640，PNG（RGB） | GitHub Social Preview / 文章头图（深色版式 + 标语） |
| `render-logo.py` | Python 3 + Pillow | 按坐标重绘三个 PNG，保证可复现 |

三个 SVG 均无外部引用、无 `<text>`、不依赖字体；字标是描边路径。主结构描边 40 单位，折算到 32×32 为 2.5 px。

## 色值

| 名称 | HEX | 用途 |
| --- | --- | --- |
| Ink | `#0B1220` | 浅色背景下的图形与字标；深色图标底 |
| Paper | `#F7F9FC` | 深色背景下的图形与字标 |
| Accent（深色面） | `#22D3EE` | 菱形网关节点（`logo-on-dark.svg` / 深色图标 / 社交图） |
| Accent（浅色面） | `#0891B2` | 菱形网关节点（`logo.svg` / 浅色 PNG） |
| Slate | `#7C8CA6` | 社交图副标题等辅助文字（仅位图，不用于标志本身） |

标志本体只用 Ink/Paper 两色加一个强调色；**去色后仍可识别**（形状差异来自「粗 U 形线 + 圆点 + 菱形」）。强调色只作点缀，不承担信息。

## 使用规范

- **最小尺寸**：完整标志（图形 + 字标）≥ **96 px 宽**，推荐 120–160 px（README 用 150 px）；仅图标 ≥ **16 px**，32×32 已实测清晰。
- **留白**：四周至少留出图形宽度 1/4 的空白，不要贴边或压在其他元素上。
- **背景**：浅色背景用 `logo.svg`，深色背景用 `logo-on-dark.svg`，图标用 `logo-mark.svg`。README 已用 `<picture>` 按 `prefers-color-scheme` 自动切换。
- **缩放**：等比缩放，保持矢量源文件；不要拉伸、压扁或旋转。
- **颜色**：只用上表色值；单色场景可整体改为 Ink 或 Paper（保留菱形与端口形状即可）。

## 禁止用法

- 不要改变图形比例、圆角、描边粗细或菱形位置；
- 不要给标志加描边、投影、外发光、渐变或 3D 效果；
- 不要把标志放进更复杂的图形里、裁切、或只取一部分；
- 不要在标志内部添加文字、数字或其他符号；
- 不要用低分辨率位图放大替代 SVG；
- 不要搭配 Epic Games / Unreal Engine 的商标、Logo 或「UE5」字样使用；
- 不要把菱形强调色用于正文文字（对比度不足）。

## 许可

UEMCP 图形标志与品牌素材随本项目共同以 MIT 许可发布，允许在指向本项目的文档/文章中引用；请勿修改图形或暗示背书。

## 重新生成 PNG

```bash
python assets/render-logo.py
```

需要 Pillow（仅此脚本使用，插件运行时不需要）。在 Pillow 12.3 / Python 3.14 上实测；脚本按 512 坐标绘制并 4× 超采样后缩放，输出后自动打印尺寸与字节数。也可指定输出目录：`python assets/render-logo.py --out-dir assets`。

`social-preview.png` 的文案使用系统字体渲染（Segoe UI / Arial / DejaVu Sans 依次回退），不进入 SVG，因此不影响矢量标志的字体独立性。
